# Introduction

This page serves as an evidence portfolio of the work completed throughout the semester in the **Embedded Systems** course, taught by **Professor Oliver Ochoa Garcia**.

## Course Objective

Learn to design and program embedded systems at the hardware level using the RP2350, integrating sensors, actuators, communication, and real-time processing to develop autonomous and functional systems.
 ---
Within this course, fundamental topics for the development and programming of **embedded systems** are covered, including:

* **Development Environment Setup** — Installation and use of the **Pico SDK, CMake, GDB, and OpenOCD**, as well as ESD safety practices.
* **Low-Level Programming** — Register-level programming, **GPIO, bitwise operations, finite state machines (FSMs)**, timers, and interrupts.
* **Serial Communication** — Implementation of **UART**, ring buffers, command-line interfaces (CLI), and debugging techniques.
* **Sensor and Actuator Interfacing** — Use of **PWM** to control LEDs, servomotors, and DC motors, as well as **ADC** for analog signal acquisition and processing.
* **Signal Processing and Generation** — Implementation of **PIO (Programmable I/O)** and **DMA** to efficiently generate, capture, and transfer signals.
* **Performance and Reliability** — Analysis of performance, latency, and jitter; use of **watchdogs**, low-power techniques, **EMC**, memory architecture, and multicore programming.
* **Testing and Validation** — Application of **unit testing** and debugging techniques to verify proper system operation.
* **Capstone Project: Micromouse** — Integration of the acquired knowledge to develop an autonomous system capable of navigating a competitive environment.
